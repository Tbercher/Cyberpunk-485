Game instructions

Menus
	Use the mouse to click on buttons.
	Options sub menu allows you to adjust volume and toggle fullscreen.

Movement
	Arrow keys
	Left and right for steering
	Up and down for acceleration and breaking
	Shift + space is time loop mechanic

Game walkthrough
	The player starts on a simple level allowing them to drive around and get a feel for the controls without the time loop mechanic in a circular map, then moves onto the exit which sends the player to level 2.
	Level 2 has the player start on the 485 highway trying to dodge cars as they speed down the lanes dodging traffic.
	After surviving for as long as they can, eventually when the player does crash and take too much damage they will move to the end screen where they can restart the game or quit.

Cheat codes
 Alt + I invincibility
Alt + P for infinite police
Alt + B for infinite Boost
Alt + N for next level
Alt + R for Restart
